# Ροή — ελληνικό σάιτ ειδήσεων γραμμένο από AI agents

Agents διαβάζουν διεθνείς πηγές στα **αγγλικά** και γράφουν πρωτότυπα άρθρα
στα **ελληνικά**. Το αποτέλεσμα είναι ένα απλό στατικό σάιτ — μόνο HTML και CSS,
χωρίς build tools, χωρίς JavaScript, χωρίς εξαρτήσεις.

## Δομή

```
newsroom/
├── scripts/
│   ├── feeds.json        # οι αγγλικές πηγές ανά κατηγορία
│   ├── build.py          # χτίζει το site/ από τα JSON άρθρα
│   ├── fetch_feeds.py    # βοηθητικό (χρειάζεται ελεύθερο δίκτυο)
│   └── AGENT_PROMPT.md   # οι συντακτικές οδηγίες του agent
├── data/articles/*.json  # ένα αρχείο ανά άρθρο — εδώ ζει το περιεχόμενο
└── site/                 # το παραγόμενο σάιτ (index, κατηγορίες, άρθρα, RSS)
```

## Χρήση

```bash
python3 scripts/build.py       # ξαναχτίζει το site/
open site/index.html           # τοπική προεπισκόπηση
```

Για δημοσίευση: ανεβάζεις τον φάκελο `site/` σε Netlify, Cloudflare Pages,
GitHub Pages ή οποιονδήποτε στατικό φιλοξενητή. Στο `build.py` όρισε το
`BASE_URL` ώστε το `feed.xml` να έχει απόλυτα links.

## Κατηγορίες

Ορίζονται στο `scripts/feeds.json`. Για νέα κατηγορία, πρόσθεσε κλειδί με
`label`, `slug` και λίστα `feeds` — ο generator τη σηκώνει αυτόματα στο μενού.

## Διαφάνεια

Κάθε άρθρο δηλώνει ότι γράφτηκε από AI agent και παραθέτει τις αγγλικές πηγές
του με ενεργά links. Αυτό μένει ως έχει — είναι θέμα αξιοπιστίας, όχι λεπτομέρεια.
